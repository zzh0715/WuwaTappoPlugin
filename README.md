# WuwaTappo 助手（WuwaTappoPlugin）

「Wuwa Tappo」桌宠游戏的非侵入式辅助插件：**不修改游戏文件、不修改游戏数据**，全部通过 Windows 公开接口（UI Automation + SendInput）与游戏交互。

## 功能

- **开关**：游戏 UI 同款圆角滑块，位于倒计时气泡上方、跟随桌宠移动；游戏关闭时自动隐藏，重开自动显示。
- **连点**：点击开关启用/停止，固定 40 次/秒（用于游戏计数）。
- **宝箱自动领取**：后台运行，宝箱就绪且计数 ≥1000 时自动领取（UIA 方式），成功后自动开始下一轮计时。
- **自动补足计数**：倒计时剩余 ≤5 分钟且计数 <2000 时，自动开启连点补足以开启两个宝箱，补足后自动关闭。
- **热键**：`Ctrl+Alt+H` 显示/隐藏开关；`Ctrl+Alt+Q` 强制停止连点。

## 构建

环境：Windows 10/11（.NET Framework 4.8 已随系统安装）。

```powershell
# 方式一：运行构建脚本
.\build.ps1

# 方式二：手动调用 csc（见 build.ps1 中的完整命令）
```

产物：`WuwaTappoPlugin.exe`（单文件，无需安装）。

## 使用

1. 将整个插件目录放在游戏安装目录下（与 `WuwaTappo.exe` 同级目录的子目录），或按需修改 `launch.vbs` 中的路径；
2. 双击桌面/目录中的 `launch.vbs`（或自行创建其快捷方式）即可先启动游戏、3 秒后自动启动插件；
3. 也可单独双击 `WuwaTappoPlugin.exe`（游戏运行中才会显示开关）；
4. 点开关 = 连点开/关；按 `Ctrl+Alt+H` 收起开关；关闭游戏后插件约 2 秒内自动退出；
5. 卸载：退出插件后删除插件目录即可，不影响游戏。

## 说明

- 所有交互均通过操作系统公开接口完成（UI Automation 读取界面状态并领取宝箱、SendInput 发送键盘输入），不注入游戏进程、不修改游戏文件或数据。
- 请自行评估并遵守游戏服务条款；本项目仅供个人学习与本地使用，使用后果自负。
