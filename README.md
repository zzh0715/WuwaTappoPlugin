# WuwaTappo 助手

「Wuwa Tappo」桌宠游戏的非侵入式辅助插件。所有交互均通过 Windows 公开接口（UI Automation、SendInput）完成，**不修改游戏文件、不修改游戏数据、不注入游戏进程**。

## 功能

- **连点开关** — 桌面上的游戏风格滑块开关：点击即开启/停止连点（固定 40 次/秒），用于快速累积游戏计数；开关位于游戏倒计时气泡上方，并跟随桌宠移动。
- **自动领取宝箱** — 后台监控宝箱槽位，宝箱就绪且计数充足时自动领取（UIA 方式）；倒计时剩余 5 分钟内若计数不足 2000，会先自动连点补足再领取，全程无需手动操作。

## 需求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（x64） |
| 运行时 | .NET Framework 4.8（Windows 10 1903+ / Windows 11 自带，无需安装） |
| 游戏 | Wuwa Tappo（`WuwaTappo.exe`） |
| 权限 | 普通用户即可，无需管理员 |

## 安装

1. 下载或编译 `WuwaTappoPlugin.exe`；
2. 将插件目录放到**游戏安装目录下**（与 `WuwaTappo.exe` 同级的子目录，例如 `WuwaTappo.Plugin\`）；
3. 运行 `setup.ps1`（右键 →「使用 PowerShell 运行」），自动在桌面创建「WuwaTappo 启动」快捷方式，将游戏和插件的启动绑定在一起。

## 使用

双击桌面「WuwaTappo 启动」快捷方式：先启动游戏，3 秒后自动启动插件。关闭游戏后插件会自动退出。

| 操作 | 说明 |
|---|---|
| 点击开关 | 开启/停止连点 |
| `Ctrl+Alt+H` | 显示/隐藏开关（插件继续在后台运行） |
| `Ctrl+Alt+Q` | 强制停止连点 |
| 双击托盘图标 | 恢复显示开关 |

## 构建

需要 .NET Framework 4.8（Windows 10/11 自带）。

```powershell
# 一键编译（产物：WuwaTappoPlugin.exe）

```
